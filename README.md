# LightRAG: контекст и обход связей на MuSiQue

Материалы воспроизводимости исследования «Формирование контекста LightRAG при ограниченном бюджете токенов». Основная серия включает 3 096 ответов на 516 вопросов из 43 корпусов. В трёх дополнительных контролях получено 1 152 ответа на тех же 192 вопроса MuSiQue из 16 корпусов. Дополнительные серии используют общую выборку.

## Пересчёт таблиц 5–10

```sh
python -m pip install -r requirements.txt
python reproduce.py --out tables.json
```

Для пересчёта достаточно Python 3.12 или новее и NumPy. Скрипт проверяет контрольные суммы, читает тексты сохранённых ответов и заново оценивает их по эталонам. Он восстанавливает средние по корпусам, парные интервалы и показатели покрытия. Оценки качества имеют шкалу от 0 до 1. Чтобы получить проценты и процентные пункты как в рукописи, умножьте значения на 100. Разность во втором контроле рассчитывается как «графовые записи минус проза», в третьем как «обход минус поиск без обхода».

В поле `exploratory_tg75_vs_vector` рассчитывается дополнительное сравнение на 192 вопросах MuSiQue из основной серии. Интервал по 20 000 парным бутстреп-выборкам 16 корпусов приведён без поправки на множественные сравнения. `data/musique_cost.csv` содержит строки TG75 и V из исходной таблицы замеров времени по корпусам. `data/development_qwen3b_summary.csv` содержит исходную сводку разведочного прогона. Поля `musique_quality_cost` и `development_qwen3b` воспроизводят время и число ответов, приведённые в разделе 8.

## Состав

- `data/main_*` содержит результаты основной серии. `data/musique_*_control` содержит результаты контролей длины, формата и обхода. Файлы `answers.jsonl` сохраняют текст каждого модельного ответа, идентификатор условия, модель, статус, фактические токены и интервалы переданного текста. `references.json` связывает идентификаторы с вопросами, эталонными ответами и опорными источниками.
- `data/main_protocol.json`, `protocol.json` отдельных серий и `data/assembly_manifest.json` фиксируют наборы, критерии, параметры и исходные контрольные суммы. `reported_result.json` и `main_reported.json` содержат исходные расчёты.
- `queue.json.gz` содержит оригинальные запросы всех условий MuSiQue. После распаковки совпадает контрольная сумма исходной очереди. `contexts_manifest.json` связывает запросы с сохранёнными длинами и хешами контекста.
- `src/ragsel` содержит код оценивания и модули исходного конвейера. `original` содержит сохранённые драйверы экспериментов и конфигурации. Для повторной подготовки с нуля этим драйверам нужны исходная сборка корпусов, сохранённые индексы или их перестроение и локальные модели. Пакет рассчитан на автономный пересчёт сохранённых ответов. Веса, бинарные среды, индексы целиком и черновик рукописи хранятся отдельно.
